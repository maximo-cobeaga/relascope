# ADR 0003: Local-Only Repository Registration in 0.0.1

## Status

Accepted for Relascope 0.0.1.

## Context

The full product vision includes local and remote repositories, including cloning from Git URLs. The first milestone only needs to prove durable multi-repository inventory and should avoid network, authentication, and Git provider complexity.

## Decision

In 0.0.1, `relascope repo add <path>` accepts only existing local directories. Git URLs and cloning are rejected with a clear error.

Each repository receives:

- a stable internal UUID generated by Relascope;
- a visible ID slug generated from the folder name or provided by `--id`;
- a canonical local path for current operation.

Visible IDs must be unique within a workspace.

## Consequences

This keeps the first milestone offline, deterministic, and safe. Remote repository support can be introduced later with explicit source metadata, authentication, cloning policy, and provider-specific error handling.
